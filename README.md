# ROODELL SERVICE — Колерная с ИИ

Веб-калькулятор: три вкладки, мобильная камера, распознавание рукописных рецептов и прайсов через серверный OpenAI API.

## Запуск

```bash
python -m pip install -r requirements.txt
export OPENAI_API_KEY="ваш_ключ"  # Windows PowerShell: $env:OPENAI_API_KEY="ваш_ключ"
uvicorn server:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000` на компьютере. Для камеры на телефоне опубликуйте приложение на HTTPS-домене (например, Render/Railway/VPS), задайте секрет `OPENAI_API_KEY` в настройках сервера. Ключ никогда не вставлять в HTML или JavaScript. HTTPS необходим для надёжной работы камеры в браузере.

Данные (прайс, рецепты, параметры) сохраняются локально в браузере устройства. Для переноса на другой телефон используйте экспорт/импорт JSON. Автоматическая синхронизация между устройствами не реализована.

ИИ-распознавание платное по тарифам OpenAI API и требует интернет. Любое распознавание нужно проверить перед сохранением, особенно рукописные числа. Плотности пигментов пока условно 1 г/мл. НДС в расчёте предполагает право на зачёт входящего НДС.
